# Maple Alert

React + TypeScript + Vite 기반 로컬 알림 도구. **1단계(화면 공유·관심 영역·설정 저장) 구현. 솔 야누스/룬 인식과 자동 알림은 아직 실행되지 않습니다.**

## 실행 및 검증

Node.js 22.12+ 또는 24 LTS에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시된 주소(기본 http://127.0.0.1:5173)를 Chrome/Edge에서 엽니다. 화면 공유는 localhost 또는 HTTPS에서 사용자의 직접 클릭으로 시작합니다. 브라우저/OS에 따라 선택 가능한 화면이 다릅니다.

```sh
npm test
npm run build
npm run preview
```

preview는 빌드 결과 확인용 정적 서버입니다. 백엔드·DB는 없으며 화면/이미지 전송 요청을 만들지 않습니다. 개발 서버 HMR은 소스 갱신용입니다. 의존성 설치에는 인터넷이 필요합니다.

## 사용법

1. 화면 공유 시작 → 게임 창 또는 모니터를 직접 선택합니다.
2. 솔 야누스 탭 → 아이콘과 숫자가 포함된 영역을 드래그합니다.
3. 미니맵 탭 → 미니맵을 드래그합니다. 원본 크롭을 확인합니다.
4. 필요하면 X/Y/너비/높이(%)를 입력하고 좌표 적용을 누릅니다.
5. 음량 설정과 알림음 테스트를 실행합니다. 개별 ON/OFF는 후속 감지 구현에 적용할 설정입니다.
6. 앱 중지 또는 브라우저 공유 종료로 스트림과 크롭 갱신을 중단합니다.

이미지로 테스트는 같은 ROI/Canvas 경로를 사용하며 공유 중 이미지를 열면 공유가 종료됩니다. 이미지는 저장되지 않습니다. ROI/ON·OFF/음량은 현재 origin의 localStorage에 저장됩니다. 포트/호스트가 바뀌면 별도 설정 공간입니다. 해상도가 바뀌면 비례 좌표를 사용하지만 게임 UI 배치 변경 시 재지정해야 합니다.

## 수동 검증

- 공유 시작/선택 취소/권한 거부/재시작 확인.
- 두 ROI 정방향·역방향 드래그, 프레임 밖 이동 시 경계 제한 확인.
- 숫자 좌표와 크롭 일치, 빈 영역과 범위 밖 입력 차단 확인.
- 새로고침 후 설정 복원 및 화면 공유가 자동 재개되지 않는지 확인.
- 게임 창과 브라우저 창 크기 변경 후 오버레이·크롭 일치 확인.
- 브라우저 공유 종료/앱 중지 후 공유 표시와 크롭 갱신 종료 확인.
- 화면 선택창이 열린 중에 앱 중지 후 뒤늦게 허용한 스트림도 종료되는지 확인.
- 로컬 이미지 입력/닫기/재공유 및 ROI 전환 확인.
- 알림음 청취/음량 0/브라우저 음소거 확인.
- Network에서 화면·이미지 업로드 요청이 없는지 확인.

자동 테스트는 좌표 변환·설정 복구·공유 수명을 검증합니다. 실제 게임 캡처와 알림음 청취는 사용 환경에서 수동 확인이 필요합니다.
