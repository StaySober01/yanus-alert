# Maple Alert

React + TypeScript + Vite 기반 로컬 알림 도구. **솔 야누스 자동 탐색·시간 판독·주기별 10초 알림을 실험 기능으로 구현했습니다. 룬 감지는 아직 미구현입니다.**

## 실행

Node.js 22.12+ 또는 24 LTS에서 실행합니다.

```sh
npm install
npm run dev
```

터미널 주소(기본 http://127.0.0.1:5173)를 Chrome/Edge에서 엽니다. localhost 또는 HTTPS에서 화면 공유를 직접 시작해야 합니다. 사전 실행 스크립트가 OCR worker/WASM/모델을 로컬 패키지에서 준비합니다. 런타임 외부 CDN·OCR 서버·백엔드·DB를 사용하지 않습니다.

## 사용

1. `야누스 알림음 테스트` / `룬 알림음 테스트`로 각각 소리와 음량을 확인합니다.
2. `화면 공유 시작`에서 게임 창이나 모니터를 직접 선택합니다.
3. 솔 야누스는 영역 지정 없이 탐색합니다. 연속 두 판독으로 남은 시간을 확인합니다.
4. 확인된 시간이 10초 이하이면 해당 주기에 한 번 알립니다. 갱신을 확인하면 새 주기를 시작합니다.
5. 미니맵은 탭을 선택해 드래그하거나 좌표를 입력할 수 있습니다. 룬 인식/알림은 아직 연결되지 않았습니다.
6. 공유 종료/앱 중지/솔 야누스 OFF 시 분석과 진행 중인 소리를 종료합니다.

`이미지로 테스트`는 파일을 업로드하지 않고 동일 픽셀 분석 경로를 실행합니다. **정지 이미지에서는 자동 알림을 내지 않으며 각 파일을 별도로 판독합니다.** 실제 스크린샷 11/10/9초, 갱신 직전, 갱신 직후, 소멸을 넣어 확인할 수 있습니다. 갱신 직후 `119`는 화면에서 숫자가 차지하는 폭까지 검사해 1:19로 해석하고 `분·초 구분자 추정`으로 표시합니다.

판독이 불확실하면 시간을 임의로 보정하지 않고 `—`로 표시합니다. 소멸 추정/일시 가림에서도 이전 알림 기록을 보존해 중복을 줄입니다. 최초 공유부터 10초 이하라면 두 관측으로 확인 후 한 번 알립니다. 공유 재시작/OFF 후 ON은 새 세션입니다.

미니맵 ROI/ON·OFF/음량은 localStorage에 저장합니다. 영상/이미지/권한은 저장하지 않습니다. 이전 솔 야누스 수동 ROI는 보존하지만 자동 탐색에 사용하지 않습니다.

알림음은 사용자가 제공한 MP3를 그대로 로컬 제공하며, 야누스는 `public/audio/yanus.mp3`(야누스10초남았어요.mp3), 룬은 `public/audio/rune.mp3`(룬나왔어요.mp3)를 사용합니다. 야누스 자동 알림에 첫 파일을 연결했습니다. 룬 파일은 별도 테스트 및 재생 API에 준비되어 있으며 룬 자동 감지 구현 시 연결합니다. 재생 중 중지뿐 아니라 파일 로딩/디코딩 중 중지해도 뒤늦게 소리가 나지 않도록 처리합니다.

## 검증

```sh
npm test
npm run build
npm run preview
```

자동 테스트: 실제 버프 PNG 탐색/숫자 OCR, 음성/중복 후보, 위치 이동/합성 확대, 설정/캡처 수명, 시간 상태 추적, 주기당 한 번 알림 이벤트, 종료 후 비동기 결과 폐기.

원본 화면은 `samples/private/`로 Git 제외되며 해당 테스트는 파일이 있는 경우에만 실행합니다. 개인정보가 없는 버프/단축키 크롭은 회귀 fixture로 포함됩니다. **제공 샘플은 조정에도 사용한 자료이며 독립적인 정확도 평가 자료가 아닙니다.**

수동 확인: 공유 허용/취소/종료, 실시간 11→10→9 알림 1회, 갱신 후 다음 주기, UI 크기 변경, OFF/ON, 브라우저 음소거/음량 0, 새로고침 설정 복원. 실제 게임의 연속 영상 및 자동 소리 청취는 사용자 환경에서 확인해야 합니다.
