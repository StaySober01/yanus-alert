# 다음 단계에 필요한 실제 샘플

현재 확보: 47초 전체 화면/기준 아이콘에 더해 11초, 10초, 9초, 갱신 직전(5초), 갱신 직후(1:19), 소멸 화면을 확보했다. 이를 기반으로 시간 판독과 주기 추적·알림을 구현했다. 솔 야누스 ROI는 사용자가 지정할 필요가 없다. 아래 표는 추가 정확도 검증용 목록이며, 같은 6장을 다시 준비할 필요는 없다. 다음에는 실제 연속 영상과 다른 숫자/배율의 독립 샘플, 룬 출현/부재 샘플이 유용하다.

현재 `이미지로 테스트`에서 PNG/JPEG/WebP(20MB 이하)를 열어 동일 ROI/Canvas 경로를 점검할 수 있다. 이미지는 서버에 전송하거나 저장하지 않는다. 개인 이미지는 Git 제외 경로 `samples/private/`에 둘 수 있다. 개인정보는 제거하되 대상 픽셀의 리사이즈/압축은 피한다.

| 대상 | 필요한 장면 |
| --- | --- |
| 솔 야누스 | 아이콘·시간이 보이는 원본 전체 화면, 15~1초(특히 11/10/9), 갱신 전후, 소멸, 다른 버프만 있는 화면 |
| 룬 | 없음/출현/유지/소멸, 보라색 유사 표식, 다른 아이콘과 겹침, 다양한 미니맵 배경 |
| 환경 | 사용 해상도·게임 UI 배율·OS 배율, 창 크기 변경 전후 |

갱신과 새 출현 검증에는 촬영 간격이 기록된 연속 이미지가 필요하다. 프레임 크기, ROI, 정답 시간(판독 불가 시 null), 아이콘/룬 존재 여부, 타임스탬프(ms), 환경 정보를 기록한다.

후속 fixture manifest 형태 (값은 실제 게임의 특성을 가정한 것이 아니라 포맷 예시):

```json
{"sequence":"user-recorded-sequence","frames":[{"file":"frame-001.png","timestampMs":0,"expected":{"yanusSeconds":null,"yanusPresent":false,"runePresent":false}}]}
```

다음 단계에 실제 ROI/환경/정답을 추가하고 detector 회귀 테스트를 연결한다. 현재 자동 테스트는 좌표·설정·캡처 수명만 검증하며 이미지 인식 정확도를 검증하지 않는다.
