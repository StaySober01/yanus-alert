# 1단계 검증 기록

현재 시간 판독/추적 검증은 [TIME_TRACKING.md](TIME_TRACKING.md), 초기 탐색 검증은 [AUTO_DETECTION.md](AUTO_DETECTION.md)를 참조한다. 아래는 초기 1단계 당시 기록이다.

- `npm test`: 2개 파일, 8개 테스트 통과.
- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드 성공.
- 의존성 설치 보안 검사: Vitest 5.0.5로 수정 후 취약점 0개.
- 브라우저 UI 확인: 초기 화면, 합성 PNG(800×450) 로컬 입력, 백분율 숫자 좌표 적용, 해당 원본 크롭 표시, 두 번째 ROI 드래그 저장, 새로고침 후 좌표 복원 확인.
- 게임 스크린샷은 사용하지 않았으며 합성 사각형 이미지는 ROI 검증만을 위한 입력이다.
- 실제 게임 공유 권한/공유 종료/해상도 변경/오디오 청취/인식 정확도는 실제 환경에서 추가 수동 확인이 필요하다. 인식 알고리즘 자체는 후속 단계 범위다.
