# 룬 감지 실험

화면 공유 → 관심 영역의 미니맵 탭 → 공유 미리보기에서 지도 전체를 드래그합니다. 좌표는 정규화하여 자동 저장됩니다. 룬 감지 스위치를 켜면 해당 영역만 500ms 간격으로 분석합니다. 위치를 바꾸거나 공유를 다시 시작하면 새로운 감지 세션입니다.

- 보라색 연결 성분을 추출하고 크기·가로세로 비율과 정규화된 마름모 마스크 일치도를 검사합니다. `RuneDetector` 인터페이스로 교체할 수 있습니다.
- 3회 연속, 최소 800ms 확인 후 `룬나왔어요.mp3`를 한 번 재생합니다. 시작 시 이미 있는 룬도 확인 후 한 번 알립니다.
- 5회 연속, 최소 2초 미검출 시 다시 알릴 수 있습니다. 잠깐 가려지는 경우에는 알림 상태를 유지합니다.
- 공유 종료, 영역 변경, 감지 OFF 시 타이머를 정리합니다. 이미지 테스트는 상태만 표시하고 알리지 않습니다.
- 기존 야누스 분석과 별도 세션으로 실행되며 서버로 전송하지 않습니다.

현재는 제공된 생성 스크린샷 한 장으로 보정한 실험 기능입니다. UI 크기에 따라 색상 성분의 폭/높이 5~32픽셀만 지원하며, 작게 축소되거나 가려진 룬은 놓칠 수 있습니다. 같은 형태의 보라색 표시는 오탐할 수 있습니다. 독립적인 정확도 검증은 아직 하지 않았습니다. 추가로 다른 맵, 해상도, 룬 소멸 전후 연속 화면을 수집해야 합니다.

`npm test`는 제공 미니맵, 해당 룬만 제거한 합성 음성 사례, 마름모·사각형 구분, 연속 확인과 재알림, 세션 중단 및 정지 이미지 무음을 검사합니다. 합성 음성 사례는 실제 소멸 샘플을 대체하지 않습니다. `npm run build`로 타입 검사와 배포 빌드를 검증합니다. `npm run dev` 후 공유 화면에서 실제 알림을 확인할 수 있습니다.
