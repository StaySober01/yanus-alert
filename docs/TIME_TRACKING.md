# 시간 판독 및 주기 알림 (3단계)

## 샘플과 결과

원본 6장은 Git 제외 경로 `samples/private/yanus-{11,10,9,before,after,absent}.png`에 보관한다. 11/10/9/갱신 전후 화면은 약 1200×680이며 아이콘은 18×20px이다. 소멸 화면은 1917×1085다. 버프 띠만 `samples/fixtures`에 회귀 테스트용으로 포함했다.

| 입력 | 실제 픽셀 기반 결과 |
| --- | --- |
| 11초 | 11 |
| 10초 | 10 |
| 9초 | 9 |
| 갱신 직전 | 5 |
| 갱신 직후 | OCR 원문 `119`, 넓은 숫자 영역과 형식을 근거로 1:19 → 79초로 해석. **구분자 추정** 표시 |
| 사라진 상태 | 아이콘 미검출, 숫자 판독하지 않음 |
| 이전 47초 샘플 | 47 |

이 데이터는 알고리즘 조정에도 사용했다. 회귀 통과는 독립 데이터에서의 정확도나 모든 배율 지원을 의미하지 않는다. 정지 이미지에 실제 촬영 간격은 없으므로 시간 추적 테스트는 명시적으로 가상 시각을 주입한다.

## 처리 경로

CanvasFrameSource → 아이콘 탐색 Worker → 노란 숫자 분리/8배 보간 → 로컬 Tesseract → 형식/신뢰도 검사 → YanusTracker → AlertAudio

아이콘 탐색은 17~58px의 14개 이산 너비를 검사하며 축소 시 기준 이미지도 저역 필터링한다. 숫자는 아이콘 높이의 28~81%에서 추출한다. 좁은 단일 글자와 여러 글자의 밝기 차이를 고려해 대비를 보정한다. 이 범위와 임계값은 현재 샘플 기준이며 교체 가능하다.

Tesseract legacy 모드, 숫자와 콜론 허용, 한 줄 판독을 사용한다. 순서에 따라 결과가 달라지지 않도록 적응형 학습/매칭을 끈다. 영문 모델에 포함된 숫자 글꼴을 사용하며 정답 값을 런타임에 입력하지 않는다. OCR 점수는 정확도 확률이 아니다.

- OCR 점수 40 미만은 판독 실패 처리.
- 정수 초는 0~59, 분·초는 한 자리 분과 00~59초 형식만 지원.
- 숫자 영역이 아이콘 너비의 65%보다 넓고 점수 55 이상이며 세 자리 숫자가 `mss` 형식에 맞으면 누락된 콜론을 추정한다. UI에서 반드시 추정임을 표시한다. 넓은 영역인데 숫자 일부만 읽힌 두 자리 값은 거부한다.
- 정확한 콜론 판독이 필요한 환경에서는 추가 고해상도 데이터로 검증/개선해야 한다.

## 상태 추적 정책

- 최초 진입은 시간 간격 0.2~4초 내의 연속 두 유효 관측으로 확정한다.
- 감소량과 실제 경과 시간 오차는 1.5초 이내이며 숫자가 증가하면 정상 카운트다운으로 인정하지 않는다.
- 첫 진입부터 10초 이하인 경우도 두 관측이 확인되면 한 번 알린다. 0초는 알리지 않는다.
- 직전 확정값보다 4초 이상 증가하면 갱신 후보. 두 관측으로 확인한 뒤 새 알림 주기를 시작한다.
- 일시적 OCR 실패에는 값을 외삽하지 않고 `—`를 표시하며 알림을 보류한다.
- 미검출이 3회 이상이고 3초 이상 지속되면 소멸 **추정** 상태. 가림과 실제 소멸을 단일 화면으로 확정할 수 없으므로 기존 알림 완료 기록을 유지한다. 낮은 시간으로 재등장해도 중복 알림하지 않는다. 확인된 갱신이 있어야 다시 알릴 수 있다.
- 분석 결과가 촬영보다 5초 이상 늦으면 영상에서는 해당 숫자를 폐기한다. 오래 멈춘 뒤의 첫 관측은 재확인한다.
- 같은 공유 세션에서 해상도가 바뀌어도 알림 기록은 유지한다. 공유 재시작/OFF 후 ON은 새 세션이다.
- 정지 이미지 테스트는 숫자만 표시하며 주기 상태를 누적하거나 자동 소리를 내지 않는다.

## 오디오와 중지

기본 합성음을 사용자 제공 MP3로 교체했다. `play(volume, 'yanus')`는 야누스10초남았어요.mp3, `play(volume, 'rune')`는 룬나왔어요.mp3를 재생한다. 파일은 `public/audio/`에서 제공하고 Web Audio로 디코딩/캐시한다. UI에 각각 테스트 버튼을 제공하며, 룬 자동 감지는 아직 연결되지 않았다.

공유 시작 클릭 시 AudioContext를 준비한다. 재생이 차단되면 `알림음 테스트`를 누르라는 메시지를 표시한다. 음량 0은 무음이다. 공유 종료/중지/OFF/언마운트 시 진행 중인 소리를 중단한다. 분석 Worker는 즉시 종료하며 OCR Worker는 초기화 중이었다면 초기화 완료 후에도 반드시 종료한다. 종료 뒤 도착한 결과는 상태/알림에 반영하지 않는다.

## 로컬 모델 제공

`npm run dev`, `npm run build`의 사전 단계가 `scripts/prepare-ocr.mjs`를 실행해 설치된 패키지에서 worker/WASM/언어 모델을 `public/ocr/`로 복사한다. 생성 파일은 Git 제외, 배포 빌드에는 포함된다. 런타임 CDN이나 외부 OCR API는 사용하지 않으며 모델과 캡처 프레임을 외부로 전송하지 않는다. 최초 패키지 설치에는 인터넷이 필요하다.

## 검증과 남은 작업

현재 검증 결과: 자동 테스트 44개 통과, TypeScript/Vite 프로덕션 빌드 성공. 실제 브라우저의 로컬 모델로 10초 및 갱신 후 79초(구분자 추정) 표시를 확인했고 브라우저 오류 로그는 없었다. 실제 자동 소리 청취를 완료했다는 뜻은 아니다.

`npm test`에서 픽셀 탐색/OCR 정방향·역방향 입력 순서, 상태 전환, 한 주기 한 번 알림, OCR 오류, 소멸/재등장, 갱신, 오래된 결과와 중지 시 폐기를 확인한다. 원본 전체 이미지가 없는 체크아웃에서는 private fixture 테스트를 건너뛴다. `npm run build`로 타입과 번들/로컬 OCR 자산을 검증한다.

실제 연속 게임 영상의 프레임 정지·다른 배율·다른 숫자와 배치·장시간 CPU 사용, 시스템/브라우저 음소거와 실제 자동 알림 청취는 추가 실사용 검증이 필요하다. 룬 감지는 다음 단계다.
